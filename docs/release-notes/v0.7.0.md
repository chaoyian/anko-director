# Anko Director v0.7.0 — Development Preview

Anko Director is a local-first AI director console for auditable Anko tabletop sessions. This first public preview separates AI-assisted proposal and narrative work from authoritative local randomness, rules, and world history.

## Highlights

- Deterministic, verifiable dice and COC 7e adjudication.
- Infinite asset canvas with relationships, status cards, and outcomes.
- Hash-verified world commits, chapter history, revisions, and branches.
- Character templates, stats, traits, and subjective memories.
- OpenAI, Anthropic, Poe, and Discord integrations with OS credential-vault support.

## Downloads

The release contains portable builds for Windows x64, Linux x64, macOS Apple Silicon, and macOS Intel. Each ZIP has a matching `.sha256` checksum file.

> **Unsigned preview:** these binaries are not code-signed or notarized. Your operating system may show a warning. Download only from this GitHub Release and verify the checksum before running.
